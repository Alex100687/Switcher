# LayoutFix

Автопереключатель раскладки и исправитель опечаток для Windows (свой Punto Switcher).
Живёт в трее, следит за набираемым словом и на пробеле/Enter/Tab решает:

| Ситуация | Что делает |
|---|---|
| `ghbdtn ` — слова нет в английском словаре, а в русской раскладке это `привет` | стирает, переключает раскладку окна на русскую, печатает `привет ` |
| `руддщ ` — наоборот | → `hello `, раскладка английская |
| `првиет `, `жызнь `, `сдесь `, `малако `, `teh ` — слова нет ни в одном словаре | → `привет `, `жизнь `, `здесь `, `молоко `, `the ` |
| `;spym ` — не та раскладка и ошибка сразу | → `жизнь `, раскладка русская |
| `tot `, `ye `, `ult ` — английские слова, но в русской раскладке это `еще`, `ну`, `где` | → русское слово, если вокруг русский текст или оно в сотни раз чаще |
| `GHBDTN ` — Caps Lock в чужой раскладке | → `ПРИВЕТ ` |
| `myVar`, `GameObject`, `API` | не трогает (идентификаторы и аббревиатуры) |
| `вобщем `, `alot ` — из таблицы автозамен | → `в общем `, `a lot ` |
| `async`, `json`, `норм`, `хз`, `пивот`, `sudo` — технические слова и сленг из белого списка | не трогает |
| `КАПС`, `слово123`, `url.com`, `snake_case` | не трогает |

### Как выбирается исправление

Кандидаты — подсказки Hunspell плюс комбинации типовых орфографических замен (а↔о, е↔и, и↔ы, з↔с, ч↔ш, э↔е…),
которых Hunspell сам не находит (`харашо → хорошо`). Каждый кандидат оценивается взвешенным расстоянием
редактирования: типовая замена 0.5, перестановка соседних букв 0.6, соседняя клавиша 0.7, пропущенная буква
0.75 (0.5, если это непроизносимая согласная или удвоение), лишняя буква 1.0 (1.2 в конце слова). К цене
прибавляется штраф за редкость по частотному словарю словоформ (субтитры OpenSubtitles, 300k русских и 50k
английских форм). Побеждает минимальная сумма — так `сдесь` уходит в `здесь`, а не в `свесь`, а `teh` в `the`,
а не в `ten`.

Исправление принимается, только если сумма ≤ 1.5, слово-цель есть в частотном списке, для 3–4-буквенных слов —
дёшево и в топе частотности (иначе `sed → sad`), а для слов с заглавной буквы — только частая цель (иначе
`Вельск → Вольск`). Набранное слово из топ-10к частотности (`чо`, `щас`, `ок`) считается настоящим и не трогается.

### Контекст языка

Для каждого окна запоминается язык последних настоящих слов. Он решает спорные случаи: слово есть в обоих
словарях (`tot`/`еще`, `руку`/`here`) — берётся язык окружающего текста; без контекста переключение только
к очень частому слову от редкого (`еще` ранг 67 против `tot` 23264, а `рук`/`her` остаётся). При исправлении
в двух гипотезах контекстный язык получает фору.

## Горячая клавиша — `Pause/Break`

* Слово ещё набирается → перевести его в другую раскладку (и переключить раскладку).
* Слово уже закончено пробелом → перевести последнее слово.
* Программа только что сама переключила/исправила слово → **откатить**. Слово при этом попадает в
  `exceptions.txt` и больше никогда не трогается — так программа учится на твоих словах.

Клавишу можно поменять в `settings.json` (`"Hotkey": "Ctrl+Shift+Space"`, любое имя из `System.Windows.Forms.Keys`).
Изменения `settings.json`, `exceptions.txt`, `autocorrect.txt`, сделанные руками, подхватываются после
«Перезапустить» в меню трея (переключатели в самом меню применяются сразу).

## Установка

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
```

Нужен .NET 8 SDK (`winget install Microsoft.DotNet.SDK.8`). Скрипт собирает self-contained exe,
кладёт его в `%LocalAppData%\Programs\LayoutFix`, включает автозапуск и запускает.
Удаление — `uninstall.ps1` (`-Purge` — вместе с настройками).

## Файлы

Всё пользовательское лежит в `%AppData%\LayoutFix\` (открывается из меню в трее):

* `settings.json` — настройки: включено/выключено, автопереключение, автоисправление, минимальная длина слова,
  горячая клавиша, звук, `ExcludedProcesses` — список программ, где LayoutFix ничего не делает
  (по умолчанию IDE, терминалы, Unity, Blender, RDP — там «исправление» кода только мешает).
* `exceptions.txt` — твои слова, которые не трогать (пополняется автоматически при откате через Pause).
* `autocorrect.txt` — свои явные замены `что_набрано = на_что` (дополняет встроенный `dict/autocorrect.txt`).
* `log.txt` — все сработавшие замены; если что-то исправилось неправильно, посмотри сюда.

Рядом с exe в `dict/`: `whitelist.txt` — встроенный белый список тех-слов, сленга и геймдев-жаргона,
`autocorrect.txt` — встроенные автозамены, `ru_freq.txt`/`en_freq.txt` — частотные списки. Эти файлы
перезаписываются при обновлении, свои слова добавляй в `exceptions.txt` / `autocorrect.txt` в `%AppData%`.

## Как устроено

* `KeyboardHook.cs` — WH_KEYBOARD_LL / WH_MOUSE_LL. Свой вывод помечается сигнатурой в `dwExtraInfo` и игнорируется.
* `WordTracker.cs` — буфер физических клавиш текущего слова; рендер в текст для любой раскладки через `ToUnicodeEx`.
* `Corrector.cs` — быстрое решение в хуке: словарь текущего языка → словарь другого языка → «неизвестное слово».
* `SpellFixer.cs` — выбор исправления: кандидаты, взвешенное расстояние (`EditCost`), частотность, автозамены.
* `TypoModel.cs` — физическое соседство клавиш (для цены «промахнулся по соседней клавише»).
* `Injector.cs` — `SendInput` (Backspace × N + Unicode-символы + пробел одним вызовом, чтобы следующие нажатия
  не перемешались) и `WM_INPUTLANGCHANGEREQUEST` для смены раскладки окна.
* `Engine.cs` — связывает всё, горячая клавиша, откат, исключения процессов.
* Словари — Hunspell `ru_RU` и `en_US` из LibreOffice, библиотека WeCantSpell.Hunspell.

Переключение раскладки делается синхронно прямо из хука — так наши Backspace'ы встают в очередь ввода
раньше следующих нажатий. Исправление опечаток (медленный `Suggest`, ~100 мс на обе гипотезы) — асинхронно:
пробел уходит в приложение сразу, а когда исправление готово, стираются слово, пробел и уже набранные буквы
следующего слова и печатаются заново. Если за это время случилось что-то, чего мы не можем смоделировать
(закончилось ещё одно слово, клик, стрелки, другое окно) — исправление пропускается, чтобы ничего не испортить.

Слово, набранное не в той раскладке **и** с ошибкой (`;spym` = `жызнь`), исправляется в обеих гипотезах —
как набрано и как читается в другой раскладке — и берётся лучшая: `жизнь` с переключением раскладки.

## Тесты

```powershell
# решения по списку слов, без клавиатуры
.\bin\Release\net8.0-windows\LayoutFix.exe --test ghbdtn hlelo async
.\bin\Release\net8.0-windows\LayoutFix.exe --test @words.txt

# сквозной тест: запускает программу, печатает в живое текстовое поле, сверяет результат
powershell -ExecutionPolicy Bypass -File tools\e2e.ps1
```

Переменные окружения для отладки: `LAYOUTFIX_DEBUG=1` (лог каждого нажатия), `LAYOUTFIX_ACCEPT_INJECTED=1`
(реагировать на синтетический ввод), `LAYOUTFIX_NO_EXCLUDE=1`, `LAYOUTFIX_DATA_DIR=<папка>`.

## Ограничения

* Границы слова — только пробел, Enter, Tab. Знаки препинания входят в слово и конвертируются вместе с ним
  (`ghbdtn?` → `привет,`).
* Не работает в программах с защитой от инъекции ввода (некоторые игры с анти-читом) и в окнах с правами
  администратора, если LayoutFix запущен без них.
* После Enter откат невозможен (в чатах сообщение уже ушло).
