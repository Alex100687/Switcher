# Switcher — заметки для ассистента

Перед любыми правками прочитай `DESIGN.md`: там вся логика, пороги, константы и грабли. После правок поведения обнови его.

Правила работы в этом репозитории:

- **Сквозной тест `tools\e2e.ps1` — только с явного разрешения пользователя.** Он захватывает экран и печатает в активное окно.
  Логику проверяй режимом `bin\Release\net8.0-windows\Switcher.exe --test @tools\testsets\<набор>.txt` — он ничего не печатает.
  Критерий: ни одного `FIX`/`SWITCH` на `jargon-keep.txt` и `tech-keep.txt`, все слова из `ortho.txt` и `two-errors.txt` исправлены
  (кроме валидного `заметьте`).
- Не меняй схему вставки текста (Injector/Engine.ApplyFix/RunInHook) без перечитывания §7 DESIGN.md — там объяснено, почему каждый шаг именно такой.
- Каждое инжектированное событие — пара key-down/key-up. Автоповтор Backspace ломает Chromium/Electron.
- `.ps1` с кириллицей сохранять как UTF-8 с BOM и CRLF; `.cs` — LF. Не правь файлы heredoc-ом из bash, если в них есть `\r`/`\n`/кавычки — пиши патчи в файл или через Write.
- Сборка/установка: `powershell -ExecutionPolicy Bypass -File install.ps1`. Релиз — см. §12 DESIGN.md (версия в `Switcher.csproj`, тег, zip → GitHub Releases через API с токеном из `git credential fill`).
- Пользователь хочет агрессивное исправление; ложные срабатывания лечим `dict/whitelist.txt` (классами слов) и порогами, а не отключением функций.
